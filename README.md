### 📡 8×8 Ku-Band AESA Tile Controller

Developing an FPGA/MCU-based controller architecture for an 8×8 Ku-band AESA tile.

The system involves:

* STM32H743-based tile controller
* Multiple beamformer ICs
* SPI-based device control
* QSPI Flash for beam-profile storage
* FPGA-to-MCU communication
* RS-422 interfaces
* DMA-driven communication
* Beam-profile management
* Fault detection and telemetry
* Synchronized beam-update control

**Technologies:**
`STM32H743` `C` `SPI` `QSPI` `FPGA` `RS-422` `DMA` `AESA` `Beamforming`
